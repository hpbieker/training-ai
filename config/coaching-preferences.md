# Coaching Preferences

Personal defaults for how training recommendations should be selected,
executed, and presented.

## Planning and Calendar

- Prefer the earliest practical workout start at or after `09:00`.
- Latest reasonable start is `20:30`; latest normal finish is `21:15`.
- Reserve 15 minutes before and after the workout for setup and cleanup.
- Treat `Focus time` and `X` as open training time.
- Treat tentative events as non-blocking, but disclose overlap by name and time.
- Treat `Lunsj` and `Middag` as movable meal requirements. Preserve their
  duration when possible; shorten `Lunsj` to 30 minutes only for a concrete
  constraint.
- Treat accepted meetings and fixed appointments as blocking unless told
  otherwise.
- Report slack after cleanup to the next fixed appointment. If the dose does
  not fit, show the shortfall and smallest optional calendar adjustment.
- A large all-hands Teams meeting may be non-blocking for indoor cycling when
  passive attendance and no active role are reasonable. Disclose the
  assumption; never apply it to outdoor cycling.

## Indoor Workouts

- Default to ERG mode and simple, flat interval prescriptions with the same
  watt target across work intervals.
- Use slope mode only when requested or naturally required by VO2Max, opener,
  standing, or harder over-threshold work.
- Prefer suitable existing workouts over parallel structures invented in chat.
- Present a short conservative/normal menu when several workouts fit.
- Change XMB power, duration, or repetitions only for a concrete readiness,
  load, time, or session-specific reason.
- Treat an existing workout's warm-up and cool-down as included in its total.
- When asked to update or prepare “today’s workout”, update `XMB VT2 TODAY` or
  `XMB VO2Max TODAY` for the selected domain and current final recommendation.
  Normally preserve its existing warm-up and cool-down.

## Fueling

- Present carbohydrate targets as countable on-bike actions, not only grams per
  hour.
- Default to `1 x 1000 ml` indoors; add a refill or second bottle well beyond
  90 minutes or in a hot room.
- Use `2 x 750 ml` outdoors for shorter/moderate rides and `2 x 1000 ml` as
  duration, heat, or intensity increases.
- Use `60–80 g carbohydrate/hour` as the normal long outdoor target unless the
  session calls for something else.
- Translate the target into SiS plus seigmenn. A simple default cue is two
  seigmenn every 15–20 minutes, adjusted for drink strength.

## Outdoor Routes

- Prefer road over gravel when both fit the training goal.
- For VT1, prefer routes with steady flow and limited stops, technical sections,
  or interval-like climbs.
- Include the Intervals.icu link to the reference activity.
- Exclude HCK-tagged activity references from solo VT1 recommendations because
  their pace and duration are not representative of solo execution.

## Analysis and Sources

- Include a fueling assessment when EatMyRide data or reported intake is
  available, distinguishing logged intake from uncertain real intake.
- Default activity-load priority is Xert, then Garmin, then Intervals.icu.
- Before VT2 or harder, check today's Intervals.icu `soreness`. A missing value
  does not block or downgrade the session; ask for it to be set. Explicit zero
  counts as present.
