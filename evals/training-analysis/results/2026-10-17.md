# Evaluation: 17 October 2026

Twenty model runs completed: five cases, two fresh runs each on `gpt-6-sol`
and `gpt-6-luna`, both at `medium` reasoning effort. A preliminary Sol control
run is excluded. The skill and analysis scripts were unchanged during the run.

The current workflow produces useful, generally cautious session analyses on
both models. This sample does not justify a larger rewrite or more research
references. The most actionable weakness is maintaining the scope of evidence
from script output into the final answer.

| Case | Sol | Luna |
| --- | --- | --- |
| Long endurance | Both answers omit the respiratory-series gap, despite using valid matched windows correctly. | Both mention the gap; one omits total session duration and labels absolute SmO2 endpoints as percentage points. |
| Threshold in ERG | Both check source WORK boundaries and distinguish delivered ERG load from ease. | First run treats detected stable segments as full bouts and infers a small shortfall; second run avoids this. |
| Short intervals | Good work/recovery synthesis; one answer calls the observed structure planned despite an unknown prescription. | Useful repeated-work synthesis; one answer reports a late HR value without identifying its block-average scope. |
| Variable outdoor | Both distinguish variable load from unavailable matched-window drift. | One answer reports block HR 124/134 as session mean/maximum instead of 119/136. |
| Missing threshold context | Both preserve unknown anchor and prescription. | One mixes BR window values (51 to 56 rather than 51 to 63); the other concludes “threshold-near” despite explicitly unknown intensity. |

Both models meet the prewritten coverage rubric in 7 of 10 answers. This equal
count hides important differences: some failures are omitted context, while
some numeric errors still pass the coverage rubric. The rubric is not a
standalone accuracy score. It should be read together with the individual
findings and source checks in [the review record](2026-10-17.json).

## Changes supported by these results

1. Make the reporting scope of decisive numbers harder to confuse: whole
   activity, source WORK interval, detected stable segment, and selected window.
   In particular, do not derive prescription completion from the duration of
   a detected stable segment. This addresses multiple observed scope errors.
2. Carry unresolved intensity through the final conclusion. A response cannot
   first say that the anchor is unknown and then classify the same work as
   threshold-near. This occurred once and warrants a targeted regression case,
   not a broad claim that either model routinely invents thresholds.
3. Keep the respiratory gap as a coverage finding, not a new universal warning
   requirement. Sol's reported window changes were supported. Adding more
   mandatory caveats to every short answer would not necessarily improve it.

No physiological conclusion rules were changed as part of this measurement.
These findings should guide a narrow correction, followed by a separately
recorded evaluation; the present scores are not post-fix scores.

## Limits and artifacts

The orchestrating assistant reviewed the answers and transcripts, knowing the
model identities. This is a small exploratory evaluation, not an independent
or blinded benchmark. There was no run without the research references, so it
cannot establish how much the articles themselves helped. The evidence was
prepared in advance; this tests the skill's interpretation and optional raw-data
inspection rather than live retrieval or preparation from scratch.

Raw answers, tool transcripts, commands, token usage and input packages are
archived locally under `outputs/training-analysis-eval/2026-10-17/` (Git-ignored).
The JSON review links each answer and transcript and records per-dimension
scores, supporting excerpts, required findings and errors. The preparation
manifest hashes sources, scripts and skill files; it did not originally hash
personal config files that the agents could also read. No statistical model
ranking or claim about isolated article effectiveness follows from these runs.
