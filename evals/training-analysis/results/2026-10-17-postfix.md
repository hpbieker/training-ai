# Post-fix evaluation: 17 October 2026

All twenty runs completed: the same five cases, two fresh sessions each on
`gpt-6-sol` and `gpt-6-luna`, at medium reasoning effort. Evidence was regenerated
with the scope changes and models read the updated skill references. No model
received earlier answers or the grading rubric. Sources, skill, scripts and
accessible Markdown config hashes were verified unchanged during this run.

## Targeted regression findings

| Previously observed failure | New observations |
| --- | --- |
| Detected stable-segment duration treated as shortened prescribed ERG work | None of four ERG answers repeats this. All describe approximately 30-minute bouts; both Sol answers give the source durations 29:57 and 29:55. |
| Outdoor block HR reported as whole-session HR | None of four outdoor answers repeats this. Luna's second answer correctly reports whole-session HR 119/136. |
| Unknown anchor acknowledged, then work called threshold-near | None of four missing-context answers repeats this. All retain unknown intensity. |

These are encouraging observations in a small rerun, not proof that the failures
are eliminated or that the changes alone caused the differences.

## Remaining issues

- Luna ERG run 1 labels HR drops of 53/57 bpm as occurring over 60 seconds.
  The cited helper values are start-to-minimum drops across 304/302-second
  recovery blocks. It also mixes a second-bout mean with a late HR value when
  describing within-bout change. The new scope fields do not cover every
  recovery metric, and explicit scope does not guarantee faithful reporting.
- Luna ERG run 2 calls ventilation approximately stable in matched windows,
  although second-bout VE increases from 132.0 to 145.4 (about 10%). This loses
  a meaningful distinction between block averages and within-block response.
- Sol missing-context run 1 calls the observed structure the completed
  “planned shape,” although prescription is explicitly unknown. It preserves
  unknown intensity, but not completely unknown prescription.
- Coverage remains variable: one long-endurance answer per model omits the
  respiratory gap. Those answers use supported window changes; omission is
  not the same as a false physiological conclusion. One Luna short-interval
  answer omits pause architecture; another describes execution but gives no
  positive interpretation of the plausible high-intensity stimulus.
- Lesser wording issues remain: ambiguous end-of-bout HR scope, an inline unit
  correction, and attribution of a local helper classification to Intervals.icu.

The manual coverage rubric passes 8/10 Sol and 7/10 Luna answers (previously
7/10 each). These counts are not accuracy scores: Luna's ERG answers cover the
required topics while still containing factual errors. See the
[per-answer review](2026-10-17-postfix.json) for scores, findings, answer excerpts
and artifact paths. The same non-blinded reviewer applied the rubric; the small
sample and judgment-dependent coverage criteria preclude a model ranking.

## Recommendation

Keep the two changes. If making one further narrow correction, expose the
recovery metric's exact interval and distinguish full-pause start-to-minimum
fall from a genuine fixed-60-second recovery measurement. Add a corresponding
regression expectation. Do not respond to this sample with more general caveats
or more research references. Neither evaluation isolates the articles' value.

## Artifacts and limitations

Raw answers, transcripts, commands, manifests and generated inputs are under
`outputs/training-analysis-eval/2026-10-17-postfix/` (Git-ignored). There were no
failed model runs. Seven exploratory tool commands in Sol sessions failed
(missing-value parsing, a Python quoting error and wrong config paths); answers
were still produced. These are separate from the physiological grading.

The runner was initially started before evidence preparation finished and
stopped on missing prompt files before any model session launched. Once
preparation completed, exactly twenty model sessions ran. Input paths and
regenerated evidence differ from the baseline; models had optional read access
to source artifacts. This is an end-to-end behavioral rerun, not an isolated
causal experiment on either individual change.
